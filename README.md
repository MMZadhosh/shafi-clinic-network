# Shafi - Clinic Data Sync System

Shafi is a lightweight web application I built to handle data transfer between different computers in a clinic environment. 

The main goal of this project is to allow medical staff to easily sync patient data and daily turns over a local network, without needing any technical or IT background.

## Features
- **Local Network Sync:** Safely transfers patient records and daily turn counts between systems.
- **Staff-Friendly UI:** A straightforward interface designed specifically for non-technical users.
- **Automated Turn Management:** Includes logic to automatically reset and manage daily patient turns.
- **Lightweight & Secure:** Built with vanilla PHP to run fast on basic local hardware, using prepared statements to prevent SQL injection.

## Tech Stack
- **Backend:** PHP 
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Database:** MySQL / MariaDB
